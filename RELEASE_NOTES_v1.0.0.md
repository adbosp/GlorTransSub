# GloSub v1.0.0

Windows 64-bit one-folder release. Download the ZIP, extract the entire folder,
then open `GloSub.exe`. No Python, pip, Visual C++ runtime, or other dependency
installation is required.

## Included

- Real-time OCR and translation for subtitle and mouse-area modes
- Text-to-speech with Smart and Queue playback modes
- AI translation and cloud TTS provider integrations
- Context memory and speaker/relationship terminology rules
- Multi-monitor support, configurable hotkeys, and light/dark settings UI
- Bundled Python, CPU PyTorch, EasyOCR, PyQt5, and runtime dependencies

Keep the `_internal` folder next to `GloSub.exe`. EasyOCR downloads the selected
language model automatically on first use; the user does not need to run any
installation command.
